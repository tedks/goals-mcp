# Changelog

## 0.1.2

Expand shared agent priming with Goals' psychology, WOOP planning/review rhythm,
and hidden sprint reward design. Add a public human overview and computer-use
instructions for local-only and non-paying users. Clarify that API/MCP requires
paid Sync, and document the new 90-day token default, longer durations and
explicit no-expiry choice.

## 0.1.1

Correct the mistakenly applied MIT license to GNU AGPL version 3 only
(`AGPL-3.0-only`). Include the full license and update package metadata and
installation URLs. The initial v0.1.0 release was withdrawn because its license
did not reflect the owner's intent. Runtime behavior is unchanged.

## 0.1.0

No longer distributed: its MIT designation was a mistake. See the correction in 0.1.1.

First standalone release: eight stdio MCP tools, three resources and a human-led
WOOP planning prompt. Connects to the Goals v1 API with revocable, scoped personal
access tokens. Preserves review gates, version preconditions, explicit obstacle
planning choices and truthful habit-day assertions. Requires Node.js 22 or later.
